## 建议统一的封面模板

以下是新制作提案，不是对历史画面参数的测量。封面画布与导出尺寸应由制作配置确定；截图中的缩略图形状不能证明源视频宽高。

1. **固定品牌行：** 将“AI趋势观察”放在稳定位置，旁边保留一期编号或日期位置。仅在实际有依据时填写日期。
2. **固定两行标题：** 第一行交代能力或场景，第二行问实际用途、限制或人的决定。每行优先控制为容易一眼读完的短句，过长则重写。
3. **固定主体区：** 使用一张清楚的场景卡片。保留一个视觉重点，少用缩小后难以辨认的小字。
4. **固定结论条：** 放一句经过核验的能力边界或操作提醒，例如“输出先核验”“付款前确认”。不把同一句口号机械套用到所有题材。
5. **固定识别，允许栏目变色：** 品牌标记、字体层级和布局保持一致，办公场景可用暖白与砖红、能力升级用深蓝与青色、代办授权用浅蓝与亮蓝。具体颜色是待制作的设计选择。

建议的标题变量：

```text
栏目：{AI工具 / 模型变化 / 机器人 / 工作应用 / 生活应用}
场景：{观众能理解的一个场景}
变化：{已核验的新能力或新事实}
封面第一行：{场景或能力，短句}
封面第二行：{对观众有什么用，或谁需要做什么决定？}
主体卡片：{一张图、一个例子或一个流程}
边界提示：{与本条内容直接相关、可支持的一句限制}
资料状态：{来源已核验 / 待核验，不发布}
```

示例结构（仅演示句式，不是新闻事实）：

- `{工作流程}交给AI？` → `{哪一步还要你看？}`
- `{工具}这次升级` → `{你能用上什么？}`
- `AI替你{完成动作}` → `{何时需要你确认？}`

## 建议的约一分钟内容骨架

以下六段与当前构建器一致，默认各 10 秒；实际配音完成后调整为总长 55–75 秒。它们是新模板的制作建议，不能写成已分析出的历史剪辑节奏；完整流程见 [每日制作流程](daily-workflow.md)。

| 时间段 | 任务 | 写作约束 |
| --- | --- | --- |
| 0–10 秒 | 提出一个与本条变化相关的问题 | 避免只有产品名或夸张感叹 |
| 10–20 秒 | 用一个工作或生活场景说明用途 | 演示、假设案例与真实操作分开说明 |
| 20–30 秒 | 展示核心结论的依据 | 主体、时间、变化有可追溯来源 |
| 30–40 秒 | 讲清限制与人的职责 | 指向这条能力实际相关的边界 |
| 40–50 秒 | 给出一个小任务的试用方法 | 步骤具体，检查结果，不虚构体验 |
| 50–60 秒 | 用一句判断收束 | 有信息增量；是否互动由选题决定 |

时长可以随内容调整，三张封面的页面标签已经显示 55–77 秒的差异。不要为了凑整分钟压缩必要来源或添加重复话。
