# 视频分析与模板校准表

用途：每条作品复制“单条作品记录”，完成若干条后填写“样本对照”。这是待填写模板，当前不包含任何已经审阅的作品结论。

## 单条作品记录

### 来源与完整性

| 字段 | 填写内容 |
| --- | --- |
| 样本编号 | `V001`（示例编号，使用时填写） |
| 账号及本人归属证据 | 待填；不要仅凭相似昵称认定 |
| 作品定位 | 本地文件名或作品链接；截图另编 `E001` 等证据编号 |
| 标题 / 发布文案原文 | 待填 |
| 发布日期 / 采集日期 | 待填 / 待填 |
| 观看范围 | 完整 / 仅片段，注明起止时间 |
| 音频情况 | 原声可听 / 静音录屏 / 音频缺失 / 未知 |
| 互动数据 | 按页面原标签记录，注明采集时刻；未显示的填“未显示” |

### 画面、声音与结构

每条观察使用 `O001` 等编号并关联证据。时间码写成 `00:00.000`，无需虚构测量精度。

| 维度 | 应记录的直接观察 | 观察与证据编号 |
| --- | --- | --- |
| 开头结构 | 第一画面、首句原文、主题何时出现；问题、结果、故事或其他结构须由画面支持 | 待填 |
| 画幅与构图 | 源文件宽高及比例（可取得时）；主体位置、留白、实拍或图文形式 | 待填 |
| 时长 | 文件总时长；主要段落起止点；若只看片段则不推定总长 | 待填 |
| 口播与字幕 | 逐句关系、每屏行数、颜色、位置、强调方式；字体无法确认时描述外观 | 待填 |
| 声音 | 人声 / 配乐 / 环境声及出现位置；语速、停顿、清晰度；音色不等于可识别身份 | 待填 |
| 封面 | 作品页实际封面、封面文字、字体外观、主体、色彩；不要将第一帧自动当封面 | 待填 |
| 节奏 | 镜头或画面切换时间、字幕换屏、停顿与转场；可记录抽样间隔或完整时间线 | 待填 |
| 正文组织 | 观点、例子、步骤、展示或故事的实际顺序 | 待填 |
| 结尾与互动 | 结束画面、最后一句、评论引导原文、是否出现行动提示 | 待填 |
| 内容语气 | 用样本原句说明口语程度、称呼、表达方式；不要单独用抽象形容词代替证据 | 待填 |

## 试稿核对

- [ ] 题材、受众与语气均有依据，或明确标为待确认。
- [ ] 脚本能对应所选结构，每个事实有来源。
- [ ] 画幅、字幕、声音、封面及节奏能对应具体规则。
- [ ] 试稿中的新尝试与保留的历史做法已区分。
- [ ] 没有把播放量差异直接写成因果结论。
- [ ] 输出状态准确：分析稿 / 制作稿 / 已渲染 / 已检查。
